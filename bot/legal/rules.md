# Правила использования — рабочий проект

1. Пользователь не должен загружать материалы, которыми он не вправе распоряжаться.
2. Запрещено использовать сервис для незаконного контента и действий.
3. Пользователь самостоятельно проверяет AI-результаты перед публикацией.
4. Модель и провайдер показываются до запуска операции, если для функции они доступны.
5. При технической ошибке, когда операция оплачена кредитами, система должна вернуть списанные кредиты.
6. Если выбранная модель ещё не подключена, кредиты не списываются.
7. Сервис может временно ограничить отдельные модели из-за лимитов, технических работ или изменений API.
8. Актуальные цены и количество кредитов показываются пользователю до запуска операции.
