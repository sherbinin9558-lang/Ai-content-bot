# Правила использования — технический черновик
1. Сервис используется законным способом.
2. Пользователь загружает только материалы, которые вправе использовать.
3. Пользователь проверяет AI-результаты перед публикацией.
4. Доступность результата зависит от выбранного провайдера и его API.
5. Нельзя обходить лимиты, использовать чужие платёжные данные или атаковать сервис.
