# AI Content Bot

Telegram AI Content Bot: пользователь выбирает результат, а внутренний AI Router выбирает провайдера.

## Основные функции

1. 🖼 Улучшить фото
2. 🛍 Карточка товара
3. 📢 Рекламный креатив
4. 🎬 Создать видео
5. 📱 Контент для соцсетей
6. ✨ AI-помощник

Дополнительно: 💳 Баланс, 📚 История, 👤 Профиль.

## Архитектура

- Python 3.11+
- aiogram 3.x
- aiosqlite
- SQLite
- AI Router с provider interface
- OpenAI-compatible text provider (опциональный)
- Amvera persistent storage `/data`

## Переменные окружения

Обязательная:
- BOT_TOKEN

Рекомендуемые:
- DATABASE_PATH=/data/bot.db
- FREE_CREDITS=10

Для текстового AI:
- AI_API_KEY
- AI_API_BASE_URL=https://api.openai.com/v1
- AI_MODEL=gpt-4o-mini

`AI_API_KEY` можно оставить пустым: бот запустится, а функции без подключённого провайдера сохранят задачу в истории без списания кредитов.

## Amvera

1. В корне проекта должны находиться `amvera.yaml`, `requirements.txt` и верхнеуровневый `main.py`.
2. Подключить репозиторий `sherbinin9558-lang/Ai-content-bot`, ветку `main`.
3. Использовать Python/Pip и Python 3.11.
4. Добавить переменные окружения, прежде всего `BOT_TOKEN`.
5. Для постоянного SQLite использовать `DATABASE_PATH=/data/bot.db`.
6. Точка запуска в `amvera.yaml` задаётся через `run.scriptName: main.py`. Для Python в Amvera это запускает `python3 main.py`. В конфигурации приложения не нужно указывать `python -m bot.main`.
7. После деплоя проверить лог: ожидается строка `Бот запущен`, затем отправить боту `/start`.

Важно: каталог `data/` в репозитории и постоянное хранилище `/data` в Amvera — разные вещи. Рабочая база должна находиться именно в `/data`.

## Локальный запуск

```bash
pip install -r requirements.txt
DATABASE_PATH=data/bot.db python -m bot.main
```

## Тесты

```bash
python -m pytest -q
```

## Состояние AI-провайдеров

Текстовые функции могут работать через OpenAI-compatible API при наличии `AI_API_KEY`.

Функции изображения и видео пока имеют интерфейс провайдера, но без подключённого внешнего API не выполняют реальную генерацию. Это намеренно отражается пользователю, а кредиты при ожидании провайдера не списываются.

## Безопасность

- секреты не хранятся в Git;
- `.env` исключён из Git;
- BOT_TOKEN не выводится в лог;
- SQL-запросы параметризованы;
- баланс защищён от ухода в минус;
- история фильтруется по `telegram_id`;
- база хранится в постоянном `/data`.
