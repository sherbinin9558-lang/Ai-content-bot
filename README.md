# AI Content Bot

Telegram AI Content Bot: пользователь выбирает нужный результат, затем сам выбирает конкретного AI-провайдера и модель. Автоматического выбора модели нет.

## Функции
1. Улучшить фото
2. Карточка товара
3. Рекламный креатив
4. Создать видео
5. Контент для соцсетей
6. AI-помощник

Дополнительно: баланс, покупка кредитов, история, профиль и юридические документы.

## Архитектура
- Python 3.11+
- aiogram 3.x + aiohttp
- SQLite в постоянном /data
- явный выбор провайдера/модели пользователем
- Provider Layer без автоматического AI Router
- Model Registry с ценой API и количеством внутренних кредитов
- Credit Ledger с атомарными/idempotent операциями
- YooKassa payment adapter + webhook verification
- СБП/карты — через доступные методы YooKassa
- AI usage ledger: провайдер, модель, операция, себестоимость, списанные кредиты
- рабочие шаблоны оферты, privacy, правил и возвратов
- GitHub Actions для тестов

## Деньги и AI-себестоимость
Пользователь платит нам за пакет внутренних кредитов. После подтверждения платежа кредиты начисляются в таблицу credit_transactions.

При AI-операции система знает выбранного провайдера, модель, конфигурационную себестоимость API и количество списываемых кредитов.

Фактические тарифы API необходимо проверять перед коммерческим запуском. Значения Nano Banana и других моделей в каталоге являются стартовой конфигурацией, а не гарантией актуального тарифа.

## YooKassa
Переменные: YOOKASSA_SHOP_ID, YOOKASSA_SECRET_KEY, PAYMENT_RETURN_URL, WEBHOOK_HOST, WEBHOOK_PORT, WEBHOOK_PATH.

Бот создаёт платёж, сохраняет его в payments, получает ссылку YooKassa и начисляет кредиты только после подтверждения статуса succeeded через API YooKassa.

Для production webhook должен быть доступен из интернета по HTTPS. Конкретный публичный URL зависит от домена и настроек Amvera.

## AI-провайдеры
Сейчас реально подключаемый адаптер в MVP — OpenAI-compatible text API при наличии AI_API_KEY. Image/video модели отображаются в каталоге, но их реальные API-адаптеры подключаются отдельно. Кредиты не списываются, если выбранная модель ещё не подключена.

## Юридическая часть
bot/legal/ содержит рабочие шаблоны публичной оферты, политики обработки персональных данных, правил использования и возвратов. Это не готовое юридическое заключение. Перед продажами нужно заполнить реквизиты самозанятого, фактические способы оплаты и согласовать документы с юристом.

## Amvera
В корне должны находиться amvera.yaml, requirements.txt и main.py.
amvera.yaml запускает python3 main.py. Не указывать python -m bot.main в поле запуска Amvera.
Для базы: DATABASE_PATH=/data/bot.db.
Если используется YooKassa webhook, HTTP-порт приложения должен быть опубликован Amvera, а webhook URL — доступен по HTTPS.
